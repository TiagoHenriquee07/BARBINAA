# Restaurante Barbina - Design Modernizado

## Bem-vindo ao Novo Site do Barbina!

Este é o site completamente redesenhado e modernizado do **Restaurante Barbina**. O novo design traz uma experiência visual sofisticada, elegante e totalmente responsiva.

---

## Principais Melhorias Implementadas

### 🎨 Design Visual
- **Paleta de Cores Atualizada**: Ouro envelhecido (#9A8456) combinado com tons escuros e cinzas para um visual sofisticado
- **Tipografia Refinada**: Cormorant Garamond para títulos (elegância clássica) e Montserrat para corpo (legibilidade moderna)
- **Espaçamento Generoso**: Melhor respiração visual com padding e margin otimizados
- **Sombras e Profundidade**: Efeitos de sombra sutis que criam profundidade sem poluição visual

### 🏗️ Estrutura e Navegação
- **Header Moderno**: Navegação fixa com efeito de transparência ao scroll
- **Menu Mobile Otimizado**: Drawer menu com animação suave para dispositivos móveis
- **Navegação Intuitiva**: Links com underline animado para melhor feedback visual
- **Breadcrumbs Implícitos**: Indicadores visuais de página ativa

### 📱 Responsividade
- **Mobile-First Approach**: Totalmente otimizado para smartphones
- **Breakpoints Estratégicos**: Adaptação perfeita em tablets (1024px) e mobile (768px, 480px)
- **Imagens Responsivas**: Grid flexível que se adapta a qualquer tamanho de tela
- **Touch-Friendly**: Botões e elementos com tamanho adequado para toque

### ✨ Componentes Melhorados

#### Seção Hero
- Imagens de fundo com gradiente overlay para melhor legibilidade
- Animações fade-up ao carregar a página
- Botões CTA (Call-to-Action) bem definidos

#### Galeria de Pratos
- Grid responsivo com 4 colunas no desktop, 2 em tablet, 1 em mobile
- Hover effects elegantes com zoom suave
- Overlay com gradiente para melhor legibilidade do texto

#### Cardápio
- Categorias com filtro interativo
- Layout limpo com nome, descrição e preço alinhados
- Animações ao carregar itens

#### Avaliações (Testimonials)
- Cards com borda esquerda colorida
- Fundo semi-transparente para destaque
- Hover effects sutis

#### Formulários
- Inputs com foco visual claro
- Validação em tempo real
- Máscara automática de telefone
- Feedback visual ao interagir

#### FAQ
- Accordion com animação suave
- Ícone de chevron que rotaciona
- Transição de altura animada

### 🎯 Funcionalidades
- **Animações de Scroll**: Elementos aparecem com fade-up ao entrar na viewport
- **Menu Mobile Funcional**: Toggle com ícone de hambúrguer/X
- **Formulário de Reservas**: Validação de data (não passado), máscara de telefone
- **FAQ Interativo**: Accordion que abre/fecha com animação
- **Cardápio Dinâmico**: Filtro de categorias com transição suave

### 📊 Performance
- **Lazy Loading**: Imagens carregam sob demanda
- **CSS Otimizado**: Sem repetição, bem organizado
- **JavaScript Minimalista**: Apenas o necessário para funcionalidade
- **Sem Dependências Externas**: Apenas Font Awesome para ícones

## Como Usar

### Instalação
1. Copie todos os arquivos para seu servidor web
2. Certifique-se de que a estrutura de pastas está mantida
3. Abra `index.html` no navegador

### Customização

#### Cores
Edite as variáveis CSS em `css/style.css`:
```css
:root {
    --primary-color: #9A8456;      /* Cor principal */
    --secondary-color: #4A4A4A;    /* Cor secundária */
    --dark-color: #1E1E1E;         /* Fundo escuro */
    --light-color: #F5F5F5;        /* Fundo claro */
}
```

#### Conteúdo
- Edite o texto diretamente nos arquivos `.html`
- Substitua as imagens de fundo em `img/`
- Atualize informações de contato no footer

#### Fontes
As fontes estão importadas do Google Fonts. Para mudar:
1. Edite o link no `<head>` de cada página
2. Atualize as variáveis CSS em `style.css`
